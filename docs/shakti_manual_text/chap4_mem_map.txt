4SECTION
SoC Device Information
The SHAKTI based SoC’ s consist of processor, memory and various Input-Output devices
(I/O). The devices in the SoC are memory mapped. Memory mapped I/O is a method to
communicate between the core and the peripheral devices. In this method the device
address and the internal registers of the devices are mapped to memory locations. The
processor and these devices communicate with the help of the AXI system bus. The next
two sections deal with the list of devices and the memory map of the devices on different
shakti based SoC’ s.
Sl. No Device name Abbreviation
1 BRAM Block Random Access Memory
2 CLINT Core Local INterrupt Controller
3 DDR Double Data Rate RAM
4 GPIO General Purpose Input Output
5 I2C Inter-Integrated Circuit
6 PLIC Platform Level Interrupt Controller
